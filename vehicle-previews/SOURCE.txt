# GTA V Vehicle Preview Library — Asset Manifest & Source Documentation

This library contains authentic in-game transparent vehicle cutouts formatted for the TRIXX menu vehicle spawner.

## Image Format & Standards
- Format: 320x180 32-bit RGBA PNG with alpha channel transparency.
- Bounding: Preserved original vehicle aspect ratio, centered on transparent canvas.
- Resampling: High-quality Lanczos filter resampling from original high-resolution in-game cutouts.
- Filename Convention: Exact lowercase GTA V model spawn identifier (e.g. `t20.png`, `oppressor2.png`, `vigilante.png`).
- Fallback Policy: Zero false fallbacks (no fallback to `adder.png` or wrong vehicle). Missing models render a neutral missing-preview placeholder.
