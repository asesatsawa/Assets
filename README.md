# TRIXX Assets Repository

Official asset repository for the TRIXX GTA V Enhanced Mod Menu.

## Directory Structure

- **JSON Maps**: High-detail JSON map builds, constructs, and custom stunt tracks (including Upside Down / Inverted Los Santos City).
- **XML Maps**: Classic Spooner, Menyoo, and Map Builder XML maps.
- **INI Vehicles / JSON Vehicles / XML Vehicles**: Complete custom vehicle loadouts, tuning setups, and saved builds.
- **JSON Outfits / XML Outfits**: Character wardrobe and outfit presets.
- **vehicle-previews**: High-resolution thumbnails and preview artwork for vehicles.
- **themes / branding / fonts / icons**: UI styling, typography, and custom visuals.
- **SpoonerAssets**: Metadata, animations, and attachment references.
